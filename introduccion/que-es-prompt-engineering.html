¿Qué es el Prompt Engineering?

Según OpenAI: "El Prompt Engineering es el proceso de escribir instrucciones efectivas para un modelo, de manera que genere consistentemente contenido que cumpla con sus requisitos. Dado que el contenido generado por un modelo es no determinístico, hacer prompting para obtener el resultado deseado es una combinación de arte y ciencia. Sin embargo, se pueden aplicar técnicas y buenas prácticas para obtener buenos resultados de manera consistente."

El Prompting, en su forma más básica, consiste en utilizar palabras para dar instrucciones a un modelo. Esto se puede hacer a través de una interfaz de chat, como cuando se interactúa con ChatGPT o Claude, o mediante el uso de una API.

El arte (y la ciencia) de dar instrucciones a estos modelos es el Prompting, y el Prompt Engineering busca crear prompts que generen contenido más predecible y preciso.

Utilizando el mismo modelo, se puede esperar obtener resultados significativamente mejores aplicando técnicas de Prompt Engineering.

Para quienes utilizan LLMs en aplicaciones de inteligencia artificial, ya sea para chatbots o para realizar trabajos complejos dentro de la aplicación, es posible reducir considerablemente los costos de la API de LLMs mediante el uso de mejores prompts.

Lo que el Prompt Engineering NO es

Ahora bien, si entendemos qué es el Prompt Engineering, también es importante comprender lo que no es.

El Prompt Engineering no es magia, ¡es ciencia! El Prompting no es la única herramienta disponible para obtener resultados mejores, más precisos y más confiables, PERO sí es la más accesible y la más fácil y rápida de implementar.

El Prompt Engineering tampoco reemplaza el pensamiento crítico. Se debe utilizar el Prompting para potenciar esas habilidades y reducir la carga mental, permitiendo hacer más y hacerlo mejor. Sin embargo, es fundamental seguir aplicando el conocimiento en desarrollo y buenas prácticas para garantizar la creación de aplicaciones seguras y listas para producción.

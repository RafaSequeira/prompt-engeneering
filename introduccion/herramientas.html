Herramientas a utilizar

Esta guía está orientada para crear prompts eficientes a la hora del desarrollo de software, cada uno puede sentirse en la libertad de utilizar ya sea Cursor, Antigravity, Claude Code, etc, inclusive utilizar los chats directamente como ChatGPT, Claude Chat, Gemini, etc, pero esto conllevaría a copiar y pegar el codigo generado en todo momento y esto puede llevar a cometer errores.

Para efectos rápidos y accesibles para la mayoría, se estará desarrollando el taller con GitHub Copilot en VS Code, por lo que se detalla la forma de integrar los LLM´s con VS code.

GitHub Copilot Chat en VS Code

1. Requisitos Previos

Antes de iniciar, asegurate de tener esto:

  • Cuenta de GitHub.
  • VS Code instalado.

2. Instalación de la Extensión

No tenés que complicarte mucho, todo se hace desde el mismo editor:

  1. Abrí VS Code.
  2. Andate al icono de Extensions en la barra lateral izquierda o presioná Ctrl+Shift+X.
  3. En el buscador, escribí "GitHub Copilot Chat".
  4. Dale clic al botón de Install.

3. Autorizá tu Cuenta

Una vez instalada, vas a ver que abajo a la derecha te sale una notificación:

  1. Hacé clic en el mensaje que dice que tenés que iniciar sesión en GitHub.
  2. Se te va a abrir el navegador; ahí solo tenés que darle permiso a VS Code para entrar a tu cuenta.
  3. ¡Listo! Si ves el icono del robotcito en la barra inferior de VS Code sin señales de error, ya estás listo.

Prompt Estándar

La técnica de prompt estándar es la base de todo lo que hacemos con los LLMs. Es simplemente pedirle algo al modelo de forma directa, sin ningún formato especial ni ejemplos adicionales.

Un prompt estándar puede ser tan directo como: «Escribí una función en JavaScript que ordene un arreglo y elimine duplicados» o «Explicame por qué el trueno da miedo». No hay nada sofisticado, solo instrucciones claras y sencillas.

Esta técnica funciona igual que cuando le preguntás algo a un amigo. Si la pregunta es vaga, la respuesta va a ser vaga. Si la pregunta es precisa, es más probable que obtengas una respuesta precisa.

Ejemplo: «Crea una aplicación de biblioteca de prompts que permita guardar y eliminar prompts, usando HTML, CSS y JavaScript.»

Los prompts estándar son el primer bloque de construcción de todas las demás técnicas. Son el punto de partida: si querés mejorar la calidad de las respuestas, empezá por formular una solicitud clara.

Ejemplo Funcional

Entrada:

"Generá una función JavaScript que tome un arreglo de números y devuelva el promedio, la suma y el número mayor."

Salida esperada:

Una función con comentarios explicativos que realice el cálculo correctamente.

Casos de uso

  • Tareas de escritura simple: "Escribí un párrafo sobre la importancia de la IA"
  • Solicitudes de código: "Crea una función que valide emails"
  • Preguntas directas: "¿Cuál es la diferencia entre var, let y const en JavaScript?"
  • Explicaciones: "Explicame cómo funcionan los closures en JavaScript"
  • Traducciones: "Traducé este texto al francés: [texto]"
  • Resúmenes: "Resumí este artículo en 5 puntos clave: [artículo]"

Consejos clave

Si el modelo no entiende lo que pedís, la culpa no es del modelo: es del prompt. Agregá más contexto o especificá mejor el formato de salida para que la respuesta sea más útil.

Los prompts estándar son ideales para tareas simples y directas. Para tareas más complejas, podés usar técnicas como zero-shot, one-shot, few-shot o ubicación de contexto.

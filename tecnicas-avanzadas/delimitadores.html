Delimitadores

Un delimitador es un borde o separador dentro de un prompt. Puede ser una coma, un punto, un bloque de texto, un tag XML o cualquier marcador que ayude a dividir la información en secciones claras.

Los modelos se benefician cuando la entrada tiene una jerarquía visual definida. Los delimitadores le dicen al LLM «esto es una sección», «esto es otra sección» y facilitan la comprensión de prompts complejos.

No importa tanto qué delimitador elegís, lo importante es ser consistente y claro. Podés usar etiquetas personalizadas, bloques con líneas, o incluso XML para separar partes diferentes del prompt.

Ejemplo: « Prompt Management Solutions - ¿Qué herramientas existen para gestión de prompts? »

Los delimitadores son útiles cada vez que el prompt tiene varias secciones o cuando necesitás darle estructura a datos extensos. Funcionan como los títulos y subtítulos de un artículo.

Ejemplo Funcional

Prompt con delimitadores:

<task>

Analiza el siguiente feedback de cliente

</task>

<feedback>

"El diseño es bonito pero tarda demasiado en cargar. A veces no puedo acceder desde el celular."

</feedback>

<output_format>

Problema: [identificar]

Severidad: [bajo/medio/alto]

Acción recomendada: [sugerir]

</output_format>

Casos de uso

  • Análisis de feedback: Separar comentarios, problemas y acciones.
  • Documentación técnica: Organizar requisitos, restricciones y consideraciones.
  • Investigación multi-tema: Dividir tópicos para que el modelo los procese independientemente.
  • Especificaciones de producto: Separar funcionalidades, restricciones y criterios de aceptación.
  • Análisis competitivo: Comparar características de múltiples productos en secciones.
  • Generación de reportes: Estruturar secciones distintas claramente.
  • Prompts complejos: Cualquier prompt que necesite múltiples contextos o instrucciones.

Cuándo usarlos

Usalos cuando el prompt es complejo o cuando hay varios bloques de información distintos. Por ejemplo, si le pedís al modelo que analice un plan de producto, dividí el prompt en áreas de investigación separadas.

Esto mejora la capacidad del modelo para procesar cada parte de forma independiente y te da más control sobre el resultado.
